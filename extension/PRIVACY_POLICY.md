**Расширение:** Visual Bookmarks StabilityInternational  
**Дата последнего обновления:** 1 апреля 2026 г.

## 1. Общие принципы

- Расширение предназначено для замены страницы новой вкладки: визуальные закладки, настройки оформления, опциональная синхронизация.
- Мы **не продаём** персональные данные пользователей и **не используем** их для показа рекламы внутри Расширения.
- Данные, которые Расширение сохраняет **только на вашем устройстве** в браузере, не передаются нам автоматически, если вы явно не включили синхронизацию с облаком или своим сервером.

---

## 2. Данные, хранимые локально в браузере

Расширение использует API `chrome.storage` (локальное хранилище расширения) для сохранения, в частности:

- списка ваших **визуальных закладок** (названия, URL, настройки плиток, цвета, закэшированные иконки сайтов в виде данных изображения);
- **настроек** интерфейса (тема, фон, сетка, поиск и т.п.);
- при использовании **Google Drive** — служебных данных синхронизации (например, идентификатор файла в облаке) и данных, необходимых для работы OAuth;
- при использовании **аккаунта Crypt-Chain** — токена доступа и профиля сессии, возвращённых сервисом по фиксированному адресу `https://crypt-chain.com` (без возможности указать другой URL API в расширении).

Эти данные остаются на устройстве пользователя в рамках хранилища расширения и не считываются нами без отдельной передачи через выбранный вами сервис (см. ниже).

---

## 3. Доступ к функциям браузера (только для отображения)

С вашего явного использования интерфейса Расширения могут запрашиваться:

- **Закладки Chrome** — для отображения списка в модальном окне; Расширение не изменяет закладки без действий в самом браузере.
- **История посещений** — для отображения списка недавних страниц в интерфейсе; история не отправляется на наши серверы.
- **Загрузки** — для отображения списка и открытия файла по вашему запросу.
- **Недавно закрытые вкладки и окна** — для отображения и восстановления по вашему выбору.

Указанные данные используются **только локально** в рамках работы Расширения и не передаются нам как оператору, если иное прямо не следует из включённой вами синхронизации.

---

## 4. Сетевые запросы и иконки сайтов

- Для отображения **favicon** у визуальных закладок фоновый процесс расширения может запрашивать **favicon** с сайтов по их URL (например, `favicon.ico`). Готовые картинки **не сохраняются** в JSON синхронизации и экспорта; при необходимости иконка снова запрашивается при открытии новой вкладки.
- При подключённой синхронизации с **Google Drive** выполняются запросы к **Google APIs** в объёме, разрешённом выбранными вами правами OAuth.
- При использовании **аккаунта Crypt-Chain** выполняются запросы к **`https://crypt-chain.com`** (в т.ч. путь `/browser-extension/…`) для входа, регистрации и синхронизации данных, которые вы передаёте этому сервису.

---

## 5. Google Drive и Google Identity

Если вы включаете синхронизацию с **Google Drive**:

- используется стандартный механизм **OAuth 2.0** Chrome (разрешение `identity`);
- Расширение обращается к **Google Drive API** для чтения/записи **одного файла** синхронизации в папке данных приложения (app data folder);
- обработка данных на стороне Google регулируется [политиками Google](https://policies.google.com/privacy).

Мы не получаем доступ к вашему паролю Google; авторизация выполняется через Google.

---

## 6. Сервис Crypt-Chain (вход и синхронизация)

Расширение использует **фиксированный** бэкенд по адресу **`https://crypt-chain.com`** (включая путь `/browser-extension` для API и страницу входа **`https://crypt-chain.com/browser-extension/login`**). Пользователь **не может** задать другой URL API в интерфейсе Расширения.

- **Регистрация и вход** в форме на новой вкладке обращаются к API Crypt-Chain; на сервис передаются введённые вами учётные данные (например, email и пароль) в соответствии с протоколом сервиса.
- **Синхронизация** закладок и настроек выполняется между браузером и **Crypt-Chain**.

Оператором персональных данных при использовании этих функций является **оператор сервиса Crypt-Chain** в объёме, определяемом его условиями и политикой конфиденциальности; настоящая политика описывает поведение **только Расширения** на стороне браузера.

---

## 7. Категории данных (для магазина Chrome Web Store)

В зависимости от того, какими функциями вы пользуетесь, могут обрабатываться:

- **История веб-навигации** — доступ через API браузера **только для отображения** списка в интерфейсе Расширения (см. раздел 3).
- **Данные для аутентификации** — токены OAuth Google и/или токены сессии Crypt-Chain, хранимые локально при вашем выборе соответствующих функций.
- **Идентифицирующая информация** — например, email и имя профиля, если вы регистрируетесь или входите через Crypt-Chain и такие данные возвращает API после входа; они хранятся локально в хранилище расширения в рамках сессии/синхронизации.

Мы **не используем** эти данные для кредитного скоринга, оценки платёжеспособности, продажи профилей третьим лицам и не собираем медицинские и платёжные реквизиты через Расширение.

---

## 8. Безопасность и хранение

- Данные в `chrome.storage` доступны только Расширению в вашем браузере в рамках модели безопасности Chrome.
- Рекомендуется использовать актуальную версию браузера и не передавать третьим лицам доступ к профилю браузера.

---

## 9. Дети

Расширение не ориентировано на детей младше 13 лет (или возраста, установленного в вашей юрисдикции). Мы сознательно не запрашиваем у детей персональные данные.

Мы можем обновлять эту политику. Актуальная версия будет доступна по тому же URL, который указан в карточке расширения в Chrome Web Store. Продолжение использования Расширения после публикации изменений означает согласие с обновлённой политикой, если иное не требуется законом.

## 11. Ваши действия

Вы можете в любой момент:

- удалить Расширение в `chrome://extensions` (локальные данные расширения будут удалены в соответствии с правилами Chrome);
- очистить данные через настройки Расширения (сброс, экспорт/импорт — если реализовано в интерфейсе);
- отозвать доступ Google к Drive в настройках аккаунта Google.
